# Unofficial Oppo UDP-20X Remote

A remote control app for the Oppo
[UDP-203](https://www.oppodigital.com/blu-ray-udp-203/) and
[UDP-205](https://www.oppodigital.com/blu-ray-udp-205/) Blu-ray players. It is
written in [Dart](https://dart.dev) using [Flutter](https://flutter.dev) and is
published on the
[Google Play Store](https://play.google.com/store/apps/details?id=one.woodbury.oppo_remote)
and the
[Apple App Store](https://apps.apple.com/us/app/unofficial-oppo-udp-20x-remote/id6742334801).

Previous generation players (such as the BDP-83, BDP-93, BDP-95, BDP-103, and
BDP-105) are not supported.
